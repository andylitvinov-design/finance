# Delivery checkpoint note

For `/delivery`, an opened pull request is an intermediate checkpoint.

The normal delivery path continues through project checks, PR health review, Spiral Validator-Critic review, repository integration, deployment verification, and live verification when the project adapter requires it.

Review-only mode is used only when the user explicitly asks for review-only, PR-only, draft-only, or no-deploy work.

The final report should state what step was completed and what step comes next.
